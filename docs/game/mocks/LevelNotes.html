What each level explains before it starts

Shown as the coral card in the briefing, once per level
1First door
New. Plan one dock: start, end, and 1 or 2 people.
Set for you: Unloading, robots off, doors
2Two cities
New. A city too big for one trailer. Give it a second dock, or lose ten minutes at each trailer swap.
Set for you: Unloading, robots off
3Robots
New. Put a city on robots and choose the fleet size. One price per robot for the whole shift.
Set for you: Unloading
4One door, two trucks
New. More cities than docks. A dock can switch city in 15 minutes; waiting parcels go to the buffer.
Set for you: Unloading, robots off
5Staggered wave
New. Parcels come in peaks. Start blocks later and change the crew size during the night.
Set for you: Unloading
6Tight store
New. The buffer is small tonight. Choose what you let wait.
Set for you: Nothing
7Robots down
New. Full hall: you need every dock and every robot. The robots are off from 01:00 to 02:00 and one truck leaves early.
Set for you: Nothing
8Peak night
New. A batch of 1,800 parcels for one city at 01:00. Not everything fits tonight: choose what stays behind.
Set for you: Nothing
9Holiday rates
New. People cost 50% more and you get 16 at most.
Set for you: Nothing
10Full house
New. Everything at once: batch, late inbound, small buffer, a limit on people.
Set for you: Nothing
